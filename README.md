# GoldAT Demo

GoldAT Demo is a simulated XAUUSD intelligence experience designed to show how the platform organizes market context, strategy signals, news, catalysts, risk controls, and trade journaling.

## Demo notice

All prices, signals, news, events, analysis results, backtests, and performance figures presented by this repository are mock or simulated data. They are not live market data, financial advice, or an execution service.

## Features

- LONG, SHORT, and NO TRADE recommendations with conviction and evidence
- More than 20 strategy models represented in one decision workflow
- XAUUSD and DXY chart demonstrations across multiple timeframes
- Macro, rates, positioning, news, and economic catalyst views
- Trade journal with import and export support
- Backtesting, validation, and risk guardrails
- Dark and light themes
- Demo disclosure shown before users enter the application

## Run locally

```bash
pnpm install
pnpm run dev
```

Open `http://127.0.0.1:5173`.

No API keys are required for the demo experience. Secrets and local environment files are intentionally excluded from source control.
